# LOOT CRYPTO brand (client's own brand)

The marks for the client fanpage **LOOT CRYPTO**, used by the `loot-crypto` theme (`remotion/src/loot.tsx`,
`channels/loot-crypto.json`). This is the channel's own brand, not a third-party logo, so videos need no trademark notice for it.

| File | Use |
|---|---|
| `loot-crypto-symbol.svg/.png` (2048²) | logomark: a 3/4 disc in off-white with a mint square in the open top-right quarter. Header chrome, end card, avatar |
| `loot-crypto-lockup.svg/.png` (3000×569) | symbol + "LOOT CRYPTO" wordmark, transparent |
| `loot-crypto-lockup-on-black.svg/.png` (3000×1020) | lockup on #08080A with margin, for previews and thumbnails |
| `loot-crypto-avatar.svg/.png` (2048²) | page avatar: symbol centred on #08080A |

**Colours:** mint `#3BE08F` (accent, the square), off-white `#F5F5F2` (the disc, ink), black `#08080A` (background),
red `#E6322D` (down moves, warnings, the short title bar only), grey `#AAAAAC` (labels, sublines).

**Type:** wordmark and Latin labels in Sora SemiBold 600, tracking 0.06em (`assets/fonts/sora_sb.ttf`, OFL). Sora has no
Vietnamese glyphs (no ạ/ọ/ệ), so Vietnamese labels use Be Vietnam Pro SemiBold at the same tracking. Titles: Be Vietnam Pro
ExtraBold. Sublines: Be Vietnam Pro Medium.

**Rules:**
- Do not recolour the mark except as a one-colour version (all off-white, or all black on mint). Keep the square mint on dark backgrounds.
- Keep the gap between disc and square. Do not rotate the mark: the open quarter is always top-right.
- Clear space is at least the size of the square around the mark.
- The geometry (quarter circle + square, cards with one sharp top-right corner, mint square bullets, the quarter-wipe transition)
  comes from this mark. Reuse it, but do not add other shapes as brand ornaments.
- The 3D version on the end card (`assets/textures/loot/plate_end.jpg`) is pre-rendered from the same geometry with `tools/loot-3d`.
